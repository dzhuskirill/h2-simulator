# Водородный завод

Симулятор себестоимости водорода по технологической цепочке: источник энергии →
производство → хранение → транспортировка → применение. Считает LCOH и углеродный
след, объясняет, что тянет цену. Источники данных и допущения — на самой странице.

Проект Евразийской технологической платформы «Водородная энергетика».
Работает как Telegram Mini App и как обычная страница.
